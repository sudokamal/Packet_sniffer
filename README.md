# Network Packet Sniffer

A CLI-based packet sniffer built in Python using raw sockets, inspired by Wireshark.

## Features
- Live packet capture
- Protocol filtering (TCP, UDP, ICMP)
- Port filtering
- Hex dump view
- Packet statistics (rate/sec)
- Logging to file

## Technologies Used
- Python
- Socket Programming
- Linux (Kali)

## How to Run

```bash
sudo python3 packet_sniffer.py
